# 06. UI 조작 흐름

## 목적
- 이 문서는 플레이어가 `지금 어디를 보고`, `어떻게 움직이고`, `무엇을 먼저 판단해야 하는지`를 UI 관점에서 정의한다.
- 전장형 모드는 화면 정보가 과하면 읽기 어려워지므로, 조작 흐름과 정보 우선순위를 함께 정리하는 것이 목적이다.

## 규칙
### HUD 기본 구성
- 상단에는 스테이지 번호, 현재 웨이브, 남은 시간, 주요 미션 조건을 표시한다.
- 중앙 전장에는 지휘 유닛, 적 경고, 타겟 하이라이트, 위험 범위 연출을 표시한다.
- 하단 또는 좌우 하단에는 이동 조작 영역과 주요 상태 정보만 배치한다.
- 기본 HUD는 `이동 판단에 필요한 정보`를 최우선으로 두고, 성장 정보나 장기 지표는 전장 화면에서 배제한다.

### 모바일 이동 UI 규칙
1. 플레이어가 이동 영역을 터치하면 VPad가 나타난다.
2. 드래그 방향에 따라 스틱과 진행 방향이 갱신된다.
3. 입력은 카메라 기준 월드 방향으로 변환된다.
4. 손을 떼면 VPad가 사라지고 이동도 멈춘다.

### PC 이동 UI 규칙
- 키보드 이동은 모바일 VPad와 동일한 방향 해석 규칙을 공유한다.
- 카메라 방향이 바뀌어도 `화면에서 본 앞/뒤/좌/우` 느낌이 크게 흔들리지 않게 맞춘다.
- PC에서 마우스 입력을 추가하더라도 기본 전장은 `연속 방향 입력` 구조를 유지한다.

### 전장 피드백 규칙
- 새 웨이브가 열릴 때는 방향과 시작 시점을 명확히 보여 주는 배너 또는 마커를 제공한다.
- 전장 밖 타겟, 이동 불가 지형, 위협 구역은 색과 형태를 달리해 구분한다.
- 지휘 유닛이 현재 집중 공격받는 중인지, 안전한지, 다음 웨이브 직전인지가 한눈에 들어와야 한다.

### 정보 우선순위 규칙
- 항상 보여 줄 정보는 `현재 웨이브`, `남은 시간`, `지휘 유닛 상태`, `위험 경고`다.
- 조건부로만 보여 줄 정보는 `다음 웨이브 상세 편성`, `부가 목표`, `디버프 상세 수치`다.
- 읽는 시간을 줄이기 위해 숫자보다 `방향`, `색`, `간단한 아이콘` 우선으로 전달한다.

### 실패 방지 규칙
- 입력이 짧게 끊겨도 전장이 멈춘 것처럼 보이지 않게, UI는 부드럽게 숨기고 보이게 한다.
- 이동 조작 UI가 전장 핵심 HUD를 가리지 않도록 배치 우선순위를 맞춘다.
- 중요한 경고는 지휘 유닛 주변과 HUD 양쪽 중 한 군데에서만 끝내지 말고, `전장 표시 + HUD 표시`를 함께 제공한다.

## 예시 시나리오
- 플레이어가 화면 오른쪽 아래를 터치하면 VPad가 나타나고, 위쪽으로 끌면 지휘 유닛이 카메라 기준 전방으로 이동한다.
- 그 순간 좌측 상단에 `WAVE 2` 배너가 뜨고, 전장 바닥에는 적 진입 방향을 알리는 경고 마커가 표시된다.
- 플레이어가 손을 떼면 VPad는 사라지고, 남은 시간과 현재 웨이브 정보만 계속 유지된다.

## 확장 포인트
- 미니맵이 필요해지면 전체 전장 지도가 아니라 `다음 위협 방향`을 요약하는 소형 레이더부터 검토하는 편이 적합하다.
- 수동 스킬 버튼이 추가되면 이동 UI와 충돌하지 않도록 `이동은 좌측, 능동 선택은 우측`처럼 화면 역할을 고정하는 방향이 좋다.
