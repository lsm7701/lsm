# 04. 웨이브 및 스폰규칙

## 목적
- 이 문서는 스테이지 난이도를 구성하는 `웨이브`, `스폰 그룹`, `유닛 편성` 규칙을 정의한다.
- 전투의 재미를 단순 체력 증가가 아니라 `언제, 어디서, 어떤 조합이 들어오는가`로 만들기 위한 기준을 세우는 것이 목적이다.

## 규칙
### 데이터 계층
- 스테이지는 여러 개의 웨이브를 가진다.
- 각 웨이브는 하나 이상의 스폰 엔트리를 가진다.
- 각 스폰 엔트리는 하나의 스폰 그룹과 연결되고, 스폰 그룹은 여러 유닛 배치 정보를 가진다.
- 정리하면 구조는 `스테이지 -> 웨이브 -> 스폰 엔트리 -> 스폰 그룹 -> 유닛 배치` 순서다.

### 스폰 그룹 규칙
- 스폰 그룹은 `유닛 구성`, `등장 순서`, `로컬 좌표`, `추가 스킬/옵션`을 가진다.
- 같은 그룹을 여러 스테이지에서 재사용할 수 있게, 그룹 자체는 편성 패턴에 집중하고 맵 고유 위치 정보는 그룹 오프셋으로 분리한다.
- 유닛 단위의 개별 특수성보다 `그룹이 어떤 압박을 만들지`를 먼저 설계한다.

### 웨이브 규칙
- 웨이브는 `등장 시점`, `기본 성장 보정`, `그룹 위치 보정`, `활성 여부`를 가진다.
- 웨이브 내부 엔트리는 동시에 나오거나, 몇 초 간격으로 순차 등장할 수 있다.
- 같은 웨이브 안에서 여러 방향 압박을 만들고 싶다면 서로 다른 그룹 오프셋을 사용한다.
- 다만 초반 기본형은 `한 번에 읽을 수 있는 적 수`를 우선해, 첫 구현에서는 과도한 동시 다발 스폰을 피한다.

### 난이도 조정 축
- 난이도는 다음 항목을 조합해 만든다.
  - 유닛 수
  - 유닛 종류 조합
  - 그룹 진입 방향
  - 등장 간격
  - 기본 레벨 보정
  - 추가 스킬 부여
- 체력과 공격력만 키우는 방식은 후순위로 두고, 먼저 `전장 문제를 어떻게 던질지`로 난이도를 만든다.

### 웨이브 연결 규칙
- 현재 웨이브의 모든 스폰이 끝났더라도 전장에 적이 살아 있으면 다음 웨이브를 열지 않는다.
- 이는 플레이어가 `정리 -> 재배치 -> 다음 대응`의 리듬을 느끼게 하기 위한 기본 원칙이다.
- 예외적으로 시간 압박형 모드가 필요하면, 별도 문서에서 `중첩 웨이브 허용`을 선언한 뒤 파생 규칙으로 분리한다.

### 초기 제안값
- 첫 테스트용 스테이지는 3웨이브에서 4웨이브 구성을 기본값으로 둔다.
- 1웨이브는 적 전투 규칙을 배우는 구간, 2웨이브와 3웨이브는 방향 압박과 조합 변형, 마지막 웨이브는 정리 시험 구간으로 설계한다.
- 각 웨이브의 개별 스폰 지연은 0초, 3초, 6초처럼 읽기 쉬운 간격에서 시작한다.

## 예시 시나리오
- 1웨이브는 전방 정면에서 근접 적 다수가 몰려와 플레이어가 후퇴와 거리 유지 감각을 익힌다.
- 2웨이브는 좌측 측면에서 원거리 유닛이 섞여 들어와, 플레이어가 엄폐와 접근 우선순위를 다시 판단하게 만든다.
- 3웨이브는 뒤쪽에서 소수 정예가 늦게 합류해, 이미 교전 중인 플레이어의 시선을 흔든다.

## 확장 포인트
- 보스 스테이지에서는 일반 웨이브 흐름 중간에 `보스 경고 -> 잡몹 소환 -> 페이즈 전환` 구조를 삽입할 수 있다.
- 협소한 통로 전장에서는 그룹 오프셋보다 `라인별 진입 우선순위`가 더 중요해질 수 있으므로 별도 스폰 타입을 추가할 수 있다.
