# 09. AI 핵심 클래스 명세

## 목적
- 이 문서는 `RTS_Game/grow_game` 작업을 여러 AI에게 나눠 줄 때, 어떤 클래스가 어떤 책임을 갖는지 빠르게 전달하기 위한 핵심 클래스 명세서다.
- 전체 코드 설명이 아니라 `수정 가능 범위`, `수정 금지 범위`, `의존 관계`, `완료 기준`을 정리하는 것이 목적이다.

### 병렬 위임 추천 단위
- A 작업: `GrowGameField_New` 중심의 웨이브/맵/이동 목적지 규칙
- B 작업: `FieldAiSelectSkillGrowGame` 중심의 적 반응과 결과 판정
- C 작업: `GrowGameStepIng_New`, `WidgetGrowGameBattleVpad`, `RTS_BattleUnitVpad` 중심의 UI/입력 조작감
- D 작업: helper와 전용 테이블 연동 구조 정리

## 예시 시나리오
- 웨이브 간격을 테이블로 빼고 싶다면 A 작업 범위로 분리한다.
- 적 추적 거리만 조정하고 싶다면 B 작업 범위로 제한한다.
- 이동 조작이 너무 둔하다는 피드백이 나오면 C 작업 범위만 먼저 검증한다.
- 좌표 복원 규칙이 여러 군데 흩어져 보이면 D 작업 범위로 helper 정리를 맡긴다.

## 확장 포인트
- 이후 실제 작업이 진행되면 각 클래스 아래에 `최근 변경 이력`, `확정된 금지사항`, `테스트 포인트`를 누적해 더 정밀한 위임 문서로 발전시킬 수 있다.
- 클래스 수가 늘어나도 이 문서에는 `실제 수정 가능성이 높은 핵심 클래스`만 남기는 것이 좋다.
